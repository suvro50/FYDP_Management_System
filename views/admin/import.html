📥 UCAM Bulk Import

Import groups from UCAM CSV data using stored procedure

ℹ️ How It Works

This feature demonstrates the sp_bulk_import_ucam_groups stored procedure. The procedure processes rows from the ucam_import_staging table, validates each row (student exists, supervisor exists, stage valid, domain valid), creates groups and memberships, and logs failures to import_error_logs.

📋 Expected CSV Format:
student_university_id, group_code, supervisor_university_id, stage_name, project_title, domain_name
